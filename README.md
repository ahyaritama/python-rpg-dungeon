# python-rpg-dungeon

## How To Play?
1. `git clone https://github.com/ahyaritama/python-rpg-dungeon.git`
2. `cd python-rpg-dungeon`
3. `python3 main.py` (For Linux)
4. `python main.py` (For Windows)
